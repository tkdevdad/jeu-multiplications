# Mission Multiplications

Jeu pour enfants pour réviser les tables de 1 à 10, utilisable sans connexion. Ouvrir `index.html` dans un navigateur récent ; aucune installation ni compte ne sont nécessaires.

## Fonctionnement

Choisir les tables, un thème, le mode de jeu et le type de réponse : pavé numérique intégré, 3 ou 6 propositions. Les modes proposés sont apprentissage, chronométré, survie et élimination. Dans ce dernier, une réponse juste ajoute une seconde et une erreur retire trois secondes. Les erreurs et les réponses choisies sont reprises en fin de partie, avec des astuces de calcul. Le score dépend de la difficulté, du temps de réponse et du type de saisie ; ses règles détaillées figurent dans le jeu.

Le nom et les scores ne sont pas enregistrés. La musique est synthétisée dans le navigateur et démarre après une interaction, selon les règles du navigateur.
